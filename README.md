# Space Engineers [Enhanced]

[Installation guide](https://deathfather.github.io/Space-Engineers-Enhanced/) | [Core Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=2929487237) | [Complete Edition](https://steamcommunity.com/sharedfiles/filedetails/?id=875707065) | [Community](https://discord.gg/V2mS2hEQAy)

This repository contains Enhanced localization files and the public mod installation guide.

Choose Complete Edition **or** Core Framework (Modular). Modular requires Weapons and exactly one Production pack: Normal **or** Hard. Start a new save for the modular rebuild.

The [Research Workshop add-on](https://steamcommunity.com/sharedfiles/filedetails/?id=3816389989) is optional. The Enhanced mod does not require Pulsar or a client plugin. Individual servers can separately require their own companion plugin.

## Website

GitHub Pages serves the `docs/` directory from `main`. It is a static, dependency-free site; open `docs/index.html` locally to preview it. The edition selector is progressively enhanced: without JavaScript both installation paths remain readable.

The guide is separate from the private Enhanced Research plugin development project. No plugin binaries, player data, or private server settings are distributed here.

Existing `MyTexts*.resx` files are the localization project. Website changes do not modify those files.

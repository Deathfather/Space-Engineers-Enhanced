01

Choose your installation

Two ways to play. Choose one, then start a fresh world.

A new save is required.

The modular rebuild changes blocks, components, and production definitions. Existing saves may have missing content or fail to load. Keep a backup of any world you care about.

Complete Edition

ALL-IN-ONE / HARD BALANCE

The full Enhanced package, built around the harder progression balance. You do not need to choose a separate modular Production pack.

  1. Subscribe on Steam Workshop

    Open Complete Edition, select Subscribe, and review its Required Items. Allow Steam to finish downloading the mod and its listed dependencies.

    Get Complete Edition ↗

  2. Start a new world

    In Space Engineers, go to New Game > Custom Game. Choose a world, open Mods, and move Complete Edition and its required dependencies into the active list.

  3. Set your world up

    The recommended starting point is 1x inventory, 1x assembler efficiency, and 1x refinery speed. Add any compatible optional modules you want, then create the world.

Do not combine: Complete Edition + Core Framework, or Complete Edition + either modular Production pack.

Modular

YOUR CHOICE OF PRODUCTION BALANCE

Start with Core, add Weapons, and choose exactly one Production pack. Optional modules are up to you.

  1. Subscribe to Core and Weapons

    Core Framework (Modular)The foundation for your Enhanced world↗ WeaponsRequired tiered weapons and ammunition↗

  2. Choose one Production pack

    Production (Normal)Vanilla base values, scaled through Enhanced tiers↗ Production (Hard)The harder, long-time Enhanced balance↗

    Normal OR Hard. Never activate both.

  3. Activate the mods in a fresh world

    Let Steam finish downloading. Open New Game > Custom Game > Mods, and activate Core, Weapons, your chosen Production pack, and their required dependencies.

  4. Add your extras and start playing

    Pick optional add-ons below. Start with 1x inventory, 1x assembler efficiency, and 1x refinery speed for the intended balance, then create the world.

Do not combine: Modular + Complete Edition, or Production (Normal) + Production (Hard).

Subscribing downloads a mod; it does not automatically activate it in every world. Workshop pages are the current reference for each module's dependencies.

OPTIONAL GAMEPLAY ADD-ON

Enhanced Research

Adds Enhanced tiered and Quantum blocks to the game's native research progression tree.

No Pulsar or client plugin required. This Workshop add-on is separate from the custom server research plugin.

Research on Workshop ↗
Installing the optional Research add-on
  1. Subscribe to Enhanced Research on Workshop and review its listed requirements.
  2. Activate it alongside your chosen Enhanced setup in the world's Mods list.
  3. Enable the world's Progression setting to use research unlocks.

On a server, follow the administrator's research setup. The Workshop tree and the custom Torch/Pulsar system are different ways to handle research.

03

Build through the tiers

Higher-tier components need higher-tier production. Advanced materials, including Clangium, Dark Matter, Dark Energy, and Trivium, support the crafting progression.

  1. T0Vanilla
  2. T1Enhanced
  3. T2Proficient
  4. T3Elite
8×

Quantum: more in the same footprint

Quantum blocks combine the equivalent of eight matching blocks in one block space, with the corresponding high component cost and weight. They are an optional branch, not a replacement for the normal tier chain.

Crafting progression is part of Enhanced. Adding the native Research tree is optional.

04

Multiplayer & servers

Joining a server

The server determines the active Workshop mods and world settings. Let the required downloads finish, and follow that server's setup instructions.

Enhanced itself does not require Pulsar. Deathfather's server requires a separate research companion plugin. Get the current client setup instructions from the community before joining that server.

Server setup & community help ↗

Hosting your own

Add your chosen edition and required dependencies to the server's Workshop mod list. Use published Workshop IDs for a public server, and keep the Complete and Modular setups separate.

Start a fresh world for this version of Enhanced. Back up your world and server configuration before changing the active mod list.

The separate research plugin is not required just to host the Workshop mod.

Updating an older Torch installation

Older Enhanced Workshop configuration or cache data can interfere with mod downloads and updates. Stop the server normally and back up its world and configuration first. Check the Torch download logs and refresh stale Workshop configuration or cached mod data as needed.

Do not delete your saves or player data. Ask for help if you are unsure which cache belongs to the affected mod. Fresh installations should not need this cleanup.

05

Quick answers

Do I need Research, Pulsar, or the companion plugin?

No, not to use Space Engineers [Enhanced]. The Research Workshop add-on is optional and uses the native game tree. Deathfather's server separately requires its research companion plugin. These are not the same installation.

I subscribed, but the mod is not in my world.

Wait for Steam Downloads to finish, then activate the subscribed mods in the world's Mods list. Subscription alone does not enable a mod. For this Enhanced version, create a fresh world instead of converting a valuable existing save.

Can I load both editions or both Production packs?

No. Choose Complete OR Modular. If you choose Modular, load Core, Weapons, and exactly one Production pack: Normal OR Hard.

Why are components or production options missing?

For Modular, verify that Weapons and one Production pack are active, along with their listed dependencies. Confirm that Complete Edition is not also active. Restart after downloads finish, and test the setup in a fresh world.

Can I keep playing an older save?

This modular rebuild requires a new save. Keep your old world backed up with its matching mod setup; adding or removing definitions can break existing blocks and production.

Where can I report a problem?

Use the community Discord or the relevant Workshop discussion. Include your edition, Production pack, active mod list, game version, a screenshot, and the relevant error log. For a server issue, include the Torch or dedicated server log excerpt.

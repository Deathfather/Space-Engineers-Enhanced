PULSAR CLIENT INSTALLATION

Enhanced Research

Get ready to join the server with timed research, your own research profile, and a queue you control.

Space Engineers 1WindowsPrivate testing

Only installing the Enhanced Workshop mod? Use the mod guide. No client plugin is required just to play the mod.

01

Install the client companion

Get the current client package from server staff.

Enhanced Research is in private testing and is not publicly listed in Pulsar yet. Ask in our Discord for the client ZIP that matches the server. The server plugin is not a public download.

  1. Install Pulsar for Space Engineers 1

    Use the official Windows installer, or follow Pulsar's portable installation instructions. Already using Pulsar? Keep your existing installation.

    Get Pulsar for Windows ↗Official setup instructions ↗

  2. Match the client package to your game runtime

    Use the build supplied for your Space Engineers 1 version. Install one build, not both.

    Interim client
    Space Engineers 1 on .NET 10. This is the build used for our current test setup.
    Legacy client
    Space Engineers 1 on .NET Framework 4.8. Only use this if your game and the server's instructions call for it.

    Pulsar Modern is for Space Engineers 2, not this plugin.

  3. Close the game and Pulsar

    Fully exit both before installing or replacing plugin files.

  4. Extract the EnhancedResearch folder

    Open your active Pulsar data folder, then its Local folder. Put the ZIP's EnhancedResearch folder there, keeping its files together.

    Our Space Engineers 1 test installation uses this location. Press Win + R and open:

    %APPDATA%\Pulsar\Legacy\Local

    Your installed folder should contain:

    Local/
  EnhancedResearch/
    plugin.xml
    plugin.dll
    EnhancedResearch.Core.dll

    The data folder can still be named Legacy when you use the Interim build. If your Pulsar installation uses a different data location, use its Local folder instead.

    Do not put these files in Space Engineers' Mods folder or nest EnhancedResearch inside another EnhancedResearch folder.

02

Enable it and join

  1. Launch Space Engineers through Pulsar

    Use the launcher matching your Space Engineers 1 runtime. Starting the game without Pulsar will not load the companion.

  2. Add it from the Plugins list

    Open the in-game Pulsar menu. Click the + below the left Plugins list, then search for Space Engineers [Enhanced] - Research and add it.

    The + on the right is for Mods. Your local client files must be installed first for this private plugin to appear.

  3. Enable, apply, and restart

    Check the plugin's Enabled box, select Apply, and restart the game through Pulsar if prompted.

  4. Connect to the server

    Use the connection details supplied by server staff and let the server's Workshop downloads finish. Once in the world, open G > Progression.

You're ready when you see Research, Purchased, and Completed.

Your research queue appears alongside the list. The normal Blocks page and block categories remain available.

The companion is required on Deathfather's research server. It does not replace the menu on unrelated servers.

03

Your research, your order

Research
Browse new research. Filter and sort the list, then choose what to purchase with Space Credits.
Purchased
Find research you have already paid for, including canceled items. Resume banked research without paying again.
Completed
Review what you have learned, separately from the research still available.
One active item
Only the first item in your queue trains. Move items up or down without losing earned research time.
Cancel without losing progress
Canceling removes an item from the queue but keeps its payment and earned time. It stops training until you queue it again.
Time keeps moving
Queued research uses real elapsed time, including time offline. Your progress belongs to your Steam account on the server.
04

Updating the client

Get the new matching client ZIP from server staff, then fully close Space Engineers and Pulsar. Replace this plugin's files in the same Local/EnhancedResearch folder and launch again through Pulsar.

Leave your other plugins and Pulsar profiles alone. Private test builds are updated manually unless staff provide different instructions.

Reinstalling the client does not erase your research. Your personal research profile is stored by the server.

05

Troubleshooting

I cannot find Enhanced Research in Pulsar.

Install the private client package first, then restart through Pulsar. Check that plugin.xml, plugin.dll, and EnhancedResearch.Core.dll are directly inside your active Local/EnhancedResearch folder.

Click the + below the left Plugins list and search there. It will not be publicly discoverable without the local package while testing is private.

The plugin is installed, but does not load.

Check that you have the correct Interim or Legacy build, that it is enabled in your active Pulsar profile, and that you launched through Pulsar. Do not mix files from the two builds. Send staff the Pulsar log if it still fails.

I still see the original Progression tree.

Confirm that you are connected to the Enhanced Research server, not a different server or a local world. Check the plugin is enabled, apply the change, and restart through Pulsar. The custom page only activates on a compatible server.

The server says my companion is missing or incompatible.

Ask staff for the client version matching the server. Close the game, install that package, enable it in Pulsar, and reconnect. Installing only the Workshop mods does not install the companion.

Do I need this just to use the Enhanced mod?

No. The Enhanced Workshop mod works without Pulsar or this client plugin. This installation is for players joining a server that requires the companion. The optional Workshop Research add-on uses the native tree and is a different product. See the Workshop mod guide for those options.

Do players need the server plugin too?

No. Players only install the Pulsar client companion. The server component is managed by the server operator and is not being publicly distributed.
